The garden is a library of agent roles and skills for working across many forks of GitHub repositories. It also has a journal, a git branch that records what the garden has done and serves as the job board and message bus the worker fleet coordinates through. The garden contains no application code. It holds only what a fleet of gardener workers reads so they can claim and run jobs.

Each chapter was written by a separate garden job from the source files it cites, and each one records which main2 commit it was grounded on. The chapters build on each other, in five parts:

  • I. Roots (chapters 1 and 2) covers why the garden has its current shape and how the machinery runs: the board, the bus, the fleet, and deploys.
  • II. Planting (chapters 3 and 4) is practical. Chapter 3 covers what to type at the liaison, and chapter 4 covers how to stand up your own instance.
  • III. Catalog (chapters 5 and 6) is reference material. It describes every role and every skill. Links to roles and skills elsewhere in the book jump to these entries.
  • IV. Tending (chapters 7 and 8) covers the procedures that work follows through the garden, and the feedback loops that keep spending within budget.
  • V. Almanac (chapters 9 and 10) covers the reference library (how it is laid out, how it grows, how workers find things in it, and why it is shaped around a limited context window) and is a reference for inference tiers: which tier and model a job gets, which worker kinds serve it, and what happens when a provider fails.
Links to source files go to main2 on GitHub, so they show the current version, which may be newer than the commit a chapter was grounded on.
